# Tracely URL Routes

Access the app at: **http://localhost:3000**

## Available Routes

| URL | Screen |
|-----|--------|
| `/` | Landing Page |
| `/login` | Login Screen |
| `/workspaces` | Workspace Screen |
| `/dashboard` | Dashboard |
| `/collections` | Collections |
| `/collections/:id` | Collection Detail |
| `/traces/:id` | Trace Detail |
| `/traces/compare/:id1/:id2` | Latency Comparison |
| `/error-analysis` | Error Analysis |
| `/topology` | Service Topology |
| `/mocks` | Mock Management |
| `/governance` | Governance |
| `/alerts` | Alert Management |
| `/alerts/thresholds` | Threshold Config |
| `/secrets` | Secret Management |
| `/reports` | Reports |
| `/replays/comparison/:id` | Replay Comparison |
| `/workflows` | Workflow Builder |
| `/request-studio` | Request Studio |
| `/load-test-results` | Load Test Results |
| `/pipeline-status` | CI/CD Pipeline Status |
| `/data-generator` | Test Data Generator |
| `/contract-testing` | Contract Testing |
| `/audit-logs` | Audit Logs |

---
